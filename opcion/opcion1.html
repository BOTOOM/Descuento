📊 Opción 1

Descuento Promocional vs Sistema

🤔 ¿Cuándo usar esta opción?

Usa esta calculadora cuando tienes un producto que debería tener un descuento promocional, pero el sistema aplica un porcentaje de descuento diferente.

💡 Ejemplo Práctico

Problema: Un producto debe venderse a $8.000 con 20% de descuento, pero el sistema solo aplica 15% de descuento.
Solución: Debes ingresar $9.412 en el sistema para que al aplicar 15% de descuento, el resultado sea $8.000.

📐 Fórmula Matemática

Precio Base = (Precio Original × (1 - Descuento Promocional)) ÷ (1 - Descuento Sistema)
