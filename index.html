💰 Calculadora de Descuentos

Herramienta para Almacenes Éxito

¿Alguna vez tuviste problemas calculando descuentos en el sistema? Esta herramienta te ayuda a encontrar el precio exacto que debes ingresar para obtener el descuento correcto.

📊

Opción 1

Descuento Promocional vs Sistema

Usa esta opción cuando tienes un producto con descuento promocional, pero el sistema aplica un porcentaje diferente.

Ejemplo:
Quieres $8.000 con 20% de descuento,
pero el sistema solo aplica 15%
🎯

Opción 2

Precio Final Directo

Usa esta opción cuando solo conoces el precio final que necesitas y el descuento que aplica el sistema.

Ejemplo:
Necesitas que el producto cueste $8.000
y el sistema aplica 15% de descuento
